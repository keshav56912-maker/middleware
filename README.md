# Express Welcome Middleware

## Run the project

1. Open this folder in VS Code.
2. In the terminal, run:

   ```bash
   npm install
   npm start
   ```

3. Send a GET request in your browser or Postman to:

   `http://localhost:3000/welcome`

Expected response: an HTML heading containing `Welcome, Guest!`.

## Submit to GitHub

After creating or opening your GitHub repository, run:

```bash
git add .
git commit -m "Implement custom welcome middleware"
git push origin main
git rev-parse HEAD
```

Submit the full commit hash printed by the last command. If your branch is named `master`, use `git push origin master`.
